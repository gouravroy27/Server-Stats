# Server Stats — System Requirements & Dependencies
#
# Server Stats is zero-dependency by design and uses core POSIX utilities
# already present in standard Linux and Unix installations.

# Core Packages (Standard in almost all Linux distributions):
# - bash (>= 4.0)
# - gawk or mawk (awk)
# - coreutils (sed, grep, cat, df, uptime, hostname, date)
# - procps or procps-ng (ps, free, vmstat)

# Optional Packages (for wireless network management):
# - network-manager (provides nmcli) OR iw

# Quick Install on Minimal / Container Environments:
# Debian / Ubuntu:
#   sudo apt update && sudo apt install -y bash gawk coreutils procps
#
# Arch Linux:
#   sudo pacman -S --needed bash gawk coreutils procps-ng
#
# Alpine Linux:
#   apk add --no-cache bash gawk coreutils procps
#
# RHEL / Rocky / Fedora:
#   sudo dnf install -y bash gawk coreutils procps-ng
